# COM pour Windows

Installateurs officiels et mises à jour signées de COM.

Téléchargez le fichier `COM_*_x64-setup.exe` depuis la dernière release.
Windows 10/11 x64, WebView2 requis (installation proposée si nécessaire).
L'installation est réservée à votre utilisateur. Vos conversations et serveurs restent sur le backend COM.

Les sources de l'application sont privées. Ce dépôt ne contient ni code applicatif ni clés de connexion.
La signature de mise à jour est distincte d'un certificat Authenticode Windows.
